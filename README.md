# AI Response Quality Evaluator Agent

## Project Overview
AI Response Quality Evaluator Agent is a multi-agent system designed to evaluate AI-generated responses based on relevance, accuracy, hallucination detection, and completeness using a RAG-based evaluation pipeline.

## Milestone 1 Deliverables
- Research on LLM Evaluation
- Hallucination Detection
- RAG Architecture
- RAGAS & TruLens Study
- System Architecture Design
- Agent Responsibilities
- Evaluation Input Module Prototype
- Reference Knowledge Base Prototype
- Dashboard UI
